# Tiers

Every component sits on exactly one tier.

## Atoms

One element, one job: a button, an input, a label.

## Molecules

A few atoms that only make sense together: a labelled field, a search input.

## Organisms

A region of an app: a table, a media library, a settings form.

## Utilities

Paint without a job of their own: a divider, a figure frame.
