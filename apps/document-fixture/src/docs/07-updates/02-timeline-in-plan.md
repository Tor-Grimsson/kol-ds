# 2.0 Timeline in Plan

Date: 27 Oct 2026

## Íslenska

Tímalínan er nú fyrsta atriðið á [Plan](#plan). Hún sýnir áfanga og verkþætti yfir vikurnar, dagsettar vörður og hléið milli áfanga, og skiptir á milli allrar tímalínunnar, mánaðar og viku. Hún les beint úr verkefnisáætluninni og er því alltaf uppfærð.

## English

The timeline is now the first item on [Plan](#plan). It shows the milestones and phases across the weeks, the dated checkpoints and the break between milestones, and switches between the whole timeline, a month and a week. It reads the project plan directly, so it is always current.
