# Typography
%% thumb: ref-type-hillstown-rubik-1.jpg

A modular type scale to try ratios on, then KOL's type tables and prose, as reference for the Atlas type system in 1.3.

## Ratio generator
%% thumb: ref-type-hillstown-rubik-1.jpg

A modular type scale from one base size and a musical ratio. Each ratio sets how far apart the sizes sit, from the gentle major second to the wide golden ratio.

::embed scale

## Type tables
%% thumb: ref-type-hillstown-rubik-2.jpg

KOL's type tables: every text style with its size, line height, weight and tracking. The reference for which styles exist and how each one is set.

::embed type-tables

## Prose
%% thumb: ref-type-kolkrabbi-1.jpg

KOL's prose specimen: headings, paragraphs, lists and quotes set together as running text. It shows how the type styles read in sequence, not one at a time.

::embed prose
