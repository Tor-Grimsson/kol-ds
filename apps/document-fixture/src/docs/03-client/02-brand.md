# Brand summary
%% thumb: link-atlascloud-is-en.png

The high-level brand, as the brief describes it. Edit as the direction firms up.

## Core

The promise, what Atlas really sells, the job the brand has to do with risk-averse buyers, and how the products sit under one name.

| | |
|---|---|
| Promise | Your data is in Iceland, under Icelandic law, with hosting, backup and disaster recovery from one provider |
| What we sell | Peace of mind |
| Brand job | Make a young company credible to risk-averse buyers, and show Atlas is the full domestic infrastructure, not only backups |
| Architecture | One brand across every product |

## Positioning

What Atlas stands for, set against what it is not, as the brief puts it: open and accountable, never a mini hyperscaler or the cheapest option.

| Atlas is | Atlas is not |
|---|---|
| Open pricing, no hidden costs | A mini hyperscaler |
| Public incident reports | Legacy hosting |
| No export fees, no lock-in | The cheapest |
| Uptime included by default | Only for developers |

## Personality

The values, personality and feelings the brand should carry, how it sounds, what it never does, and the one topic where it takes a stand.

| | |
|---|---|
| Values | Transparency, simplicity, reliability, accountability |
| Personality | Reliable and trusted, also young, quick and alive |
| Feelings | Peace of mind, trust, pride, power |
| Voice | Calm and factual, plain and human, humor only when backed by uptime numbers |
| Never | Fear-mongering, competitor bashing, party politics |
| Stand | Only on jurisdiction and data sovereignty |

## Key messages

The four messages the brief names, in the client's words. They are critiqued and sharpened in 1.4 before they reach the website and the mockups.

| Message |
|---|
| We secure Iceland's technical independence |
| Digital sovereignty means full control over infrastructure, data and digital services |
| At Atlas you know where your data is and under which jurisdiction it falls |
| Gögnin heim! ("Data home!") |

## Visual direction

The base form, the clichés to avoid, where the identity has to work, and the moodboard Atlas still has to share with the agency.

| | |
|---|---|
| Base form | Hexagon, like basalt columns: solid, no weak points, tiles endlessly |
| Avoid | Padlocks, shields, green binary code, hooded hackers, blue globes, Vikings, flag colors |
| Must work | In Icelandic and English, and stretch later to foreign markets and AI |
| Moodboard | Exists, to be shared by Atlas |

## Open questions

Questions the brief leaves open for the agency: the name, the fifth element and how to talk about cost. Each one is answered during M1.

| Question | Note |
|---|---|
| Keep the name Atlas? | Crowded in tech and close to Atlassian; registered by Atlas Cloud ehf. in class 42 |
| What is the fifth element? | A device people recognize without the logo; the other four are not defined |
| How to talk about cost? | Brief says both "cheaper than domestic" and "not the cheapest" |
