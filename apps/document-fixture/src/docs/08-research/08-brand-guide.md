## Íslenska

**Hvað mun vörumerkjahandbók Atlas innihalda?** Hún byggir á vörumerkjahandbókarsniðmáti Kolkrabba, sem byggt er á handbókunum átta í [4.0 Brand guides](#brand-guides). Þessi grein tekur saman kafla sniðmátsins. Hún vex í gegnum [1.6 Brand guide](#project--brand-guide), 7. – 16. des.

## English

**What will Atlas's brand guide contain?** It starts from the Kolkrabbi brand guide template, built from the eight guides in [4.0 Brand guides](#brand-guides). This paper notes the template's sections. It grows through [1.6 Brand guide](#project--brand-guide), 7 – 16 Dec.

![[gd-template-general.png|The brand guide template, opening on How to use this guide]]

## The sections

| Part | Chapter | What it states |
|---|---|---|
| Overview | 00 Intro | Who the guide is for, how it is organized, and which edition this is |
| | 01 About | Who makes the brand, where, since when, and what it works against |
| | 02 Key messages | Three to four lines the brand returns to everywhere |
| | 03 Voice | How the brand sounds, the words it uses, and how things are named |
| Logo | 04 The mark | What the marks are and why |
| | 05 Logo | Lockups, clear space, minimum size and misuse |
| Foundations | 06 Color | Every colour in four systems, and which pairs are safe to read |
| | 07 Type | The faces and their roles, the scale, and the fallback |
| | 08 Elements and grid | One base unit that sets the margins, the grid and the spacing |
| Graphics | 09 Imagery | A brief someone else can shoot from |
| | 10 Icons | Sizes and one style rule |
| Assets | 12 Applications | The brand's own touchpoints, each with its file |
| Social | 13 Templates and tools | Post sizes, the deck, the generators, and where to get them |
| Governance | 14 Co-branding | How the brand appears beside partners |
| | 15 Running the guide | Who owns the brand, what needs approval, where the files are |

Chapter 11, Motion, is switched off: it belongs to the product, not the brand.

## Already decided for Atlas

- The guide is in Icelandic.
- Figma is the asset home and the source of truth.
- The guide is a living document that grows through M2 as templates are added.
