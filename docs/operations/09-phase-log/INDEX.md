# Phase log

Every run of work, newest first. An entry holds two tables — the **phases** (what was done, with the
docs it touched) and the **decisions** (who ruled what) — and links the plan it ran from. Not a
package changelog: this is where to look for *"did I already raise this"* or *"that was on a list"*.

A finished plan is copied into `_files/` unchanged and does not change again. Each run adds its entry
here in the same pass that closes it.

**Titles fit the rail:** at most three words and 22 characters, no leading *The*; `+` joins a pair
(`App frame + curves`). A longer title clips in the Development rail. Enforced by
`validate:metadata` (M3).
