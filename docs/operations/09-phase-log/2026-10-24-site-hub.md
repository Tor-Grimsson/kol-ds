# Site hub

**Run:** 2026-10-24 (one goal, the evening after the Studio milestone) · **Plan:** [[_files/plan-2026-10-24-site-hub|plan-2026-10-24-site-hub]] · **State:** W1, W4 and the last pass built, 2.1 built; W2 (the look and the pages) is his; W3 (the pass and the site repos) parked

## What it is

What studio-hub is for the Studio apps, for the sites on the site rail: brand.kolkrabbi.io, brand.another-creation.xyz and every `brand.<domain>` carry their own copy of the frame (`BrandLayout.jsx`, and acyr a forked `SideNav.jsx`). `apps/site-hub` is that frame from the packages, on dummy data, open-ended — the layout and a few pages, so the user can say what a site should look like and which pages it has.
