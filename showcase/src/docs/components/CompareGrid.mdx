## Usage

```jsx
import { CompareGrid } from '@kolkrabbi/kol-component'

<CompareGrid
  labels={{ a: 'monitor', b: 'kol-icons' }}
  items={names.map((n) => ({ id: n, label: n, a: local[n] && (({ size }) => <LocalIcon name={n} size={size} />), b: ({ size }) => <Icon name={n} size={size} />, state: stateOf(n) }))}
/>
```

## Behavior

Each item is a pair of plates — A beside B, each side named in words, the item's name under the pair.
A side draws at the chosen size on an `IconPlate`, with its real 16px size beside its name. A side may be a
node or a renderer `({ size, ground, guide }) => node`. A missing side is an empty plate carrying its
`candidate` (or the item's name). The toolbar is controls: size 24 · 48 · 96 · 128, ground, guide, and — when items carry a
`state` — a filter with counts. `state` also shows as a chip on the item.
