## Usage

```jsx
import { SectionHero } from '@kolkrabbi/kol-component'

<SectionHero media={{ src, kind: 'image' }} label="KOLKRABBI" headline="Full-bleed media hero" actions={<Button>View work</Button>} />
<SectionHero variant="split" headline="A title card in two halves" />
```

## Behavior

**One hero for every page.** `media` (default): cover-fit background media filling a fixed-height section, an optional surface scrim, and the text in the hero's own `OverlayGlassPanel` as a [SectionText](/components/section-text) — or pass `panel` and your node renders verbatim (what every `FullBleedHero` call site does; that name is a deprecated alias of this component). `panelProps` reaches every knob on the glass: `padding`, `maxWidth`, `surfaceOpacity`, `blur`, `gap`, `className`. `split`: the viewport in two halves — media fills one edge to edge (no media → `AssetPlaceholder`), the headline centred and **uppercase by role** in the other, no glass panel; `align` picks the media side; below `md` the halves stack, media first. Only what you pass renders. `media` as an **array** is the carousel (autoplay, one glass panel per slide — FeaturedCarousel is the engine); **no media** is the text-only hero, the composed text on the surface. `justify="end"` pins the content to the foot, `veil` grades the media under it, and `foot` + `overlap` render a node across the fold.
