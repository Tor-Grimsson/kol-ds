## Usage

```jsx
import { SubPageHero } from '@kolkrabbi/kol-framework'

<SubPageHero backTo="/" backLabel="← Back" label="Reference" title="Icons" lede="…" />
```

## Behavior

The sub-page sibling of [BrandHero](/components/brand-hero): an optional
back link (helper-12, wide tracking) above an optional label eyebrow, then
the `kol-sans-display-01` title and lede. Reach for it on detail pages that
need a route back up; BrandHero owns the top-level landing.
