## Usage

```jsx
import { MediaLibrary } from '@kolkrabbi/kol-component'

<MediaLibrary variant="browse" client={mediaClient} title="KOL-MEDIA" folderTree={tree} />
<MediaLibrary variant="library" client={mediaClient} title="KOL-MEDIA" settings={settings} onSettingsChange={save} />
<MediaLibrary variant="modal" open={open} client={mediaClient} accept={['image', 'video']} onSelect={pick} onClose={close} />
```

## Behavior

kol-r2b2's app, cut in two (MediaLibraryPages, 2026-08-27): **browse** is folder / files — the bucket dropdown (from `client.buckets()`), the crumb line with the ROW | COLUMN toggle, `ColumnBrowser` on the flat key space, the count line; **library** is the content-filters wall — FILES · kind chips · search · SELECT / FLAT · grid | list | off · sort, the cards with the frame-corner download, paging, the inspector lightbox, the settings drawer. Both render read-only unless the client carries the write seams. The modal variant is the picker, as before. **The client is injected**, never imported. `page` is a deprecated alias of `library`; `MediaBrowser` / `MediaPicker` are thin aliases.
