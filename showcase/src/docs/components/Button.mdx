## Usage

```jsx
import { Button } from '@kolkrabbi/kol-component'

<Button variant="primary" iconRight="arrow-right" onClick={next}>
  Continue
</Button>
```

## Variants

Four variants share one padding scale with `.kol-control` — sm 4/12 · md 6/16 ·
lg 8/20. `primary` is the default; **nothing defaults to `outline`** (standing
law — outline needs a stated reason at the call site).

Icon-only is a geometry condition, not a variant: `.kol-btn-icon` pads equally
on all sides at every variant, giving square 24/30/36 boxes.
