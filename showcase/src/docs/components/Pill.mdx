## When to use

**The STATIC chip** — a label, category or status word. Not clickable. The
chip family splits three ways (chip law, 2026-07-30): Pill is decoration,
[Tag](/components/tag) is interactive/filterable (a Tag with no handler is a
Pill wearing the wrong name), [Badge](/components/badge) is system status or
a count. Defaults follow the standing laws: `primary` (the grey fill —
nothing defaults to outline) and `sm` (chip law). The variant vocabulary is
Button's: `primary` / `secondary` / `inverse`.
