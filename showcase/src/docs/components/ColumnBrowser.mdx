## Usage

```jsx
import { ColumnBrowser } from '@kolkrabbi/kol-component'

<ColumnBrowser objects={objects} prefix={prefix} onPrefix={setPrefix} quickLook={quickLook} onQuickLook={setQuickLook} urlOf={(o) => publicUrl(o.key)} />
```

## Behavior

One column per path segment of `prefix` (column 0 is the root). Picking a folder sets the prefix to it and truncates deeper columns; picking a file highlights it and opens a 320px **preview column** — the image (or the kind label), the name, and Kind · Type · Size · Dimensions (image + video, off the loaded media) · Length (audio + video, `m:ss`, off `loadedmetadata`) · Date — `…` until the metadata lands. Both are captured on the media frame, so a consumer `renderPreview` node's own `<img>` / `<video>` / `<audio>` feeds them too (ColumnBrowserMediaFacts, kol-r2b2 2026-08-27). Rows wear the Table's cell metrics; selected and cursor rows draw the hover fill (user ruling: "make hover state the selected state"). Height is fixed at 528px (12 × 44) so the browser never jumps; columns scroll. Keyboard is Finder's: ↑/↓ move in the column (a folder opens as you land on it, a file previews), → into the open folder, ← back to its parent; **space** is Quick Look — `onQuickLook({ files, index })` over the column's files; while open, ↑/↓ step the file and space closes. Built and ruled in kol-r2b2 first (2026-08-27), shipped verbatim; the app bits are seams with defaults.
