## Usage

```jsx
import { SectionCta } from '@kolkrabbi/kol-component'

<SectionCta eyebrow="/ CONNECT" promptLabel="WORKING ON A PROJECT?" heading="SEND A MESSAGE" contactLabel="CONTACT" email="hello@kolkrabbi.io" />
```

## Behavior

A large display wordmark on the left and a right column of stacked rows, each a [SectionText](/components/section-text) — the label in the helper voice (uppercase by role), the value as a heading-01; a row with `href` renders its value as a link. Columns sit side by side from `md` up and stack below, inside a 1600px centred cap; the section's surface stays full width. Row labels wear the set's eyebrow voice. `CtaGlobal` is the deprecated alias — identical props. `variant="centered"` is the quiet mid-page tier — a short rule, a heading, a mono line and Buttons, centred — that was `FoundryCTA` (now a deprecated alias of it).
