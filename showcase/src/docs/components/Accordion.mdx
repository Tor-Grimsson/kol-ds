## Behavior

Composition-based: `<Accordion>` wraps `<AccordionPanel>` children. Each panel
owns its open/closed state independently — **multiple panels can be open at
once** (additive). For single-open behavior, lift the state to the parent and
pass controlled `open` + `onToggle` to each panel.
