## Usage

```jsx
import { ViewToggle } from '@kolkrabbi/kol-component'

<ViewToggle viewMode={view} onViewChange={setView} />
```

## Variants

Three body plans: `text` — segmented bare buttons (active =
kol-control--filled, inactive bare text-meta); `icon` — a bordered chip-row
of square icon buttons; `single` — one binary toggle button that flips
between the two `options` and shows the current label. Companion to
[SegmentedToggle](/components/segmented-toggle): reach for that when the
cells share one joined shell.
