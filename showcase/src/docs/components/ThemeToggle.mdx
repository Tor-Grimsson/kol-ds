## Usage

```jsx
import { ThemeToggle } from '@kolkrabbi/kol-framework'

<ThemeToggle />                            // THE button — grey fill, glyph + label
<ThemeToggle fill="none" label={false} />  // quiet square for icon bars
<ThemeToggle fullWidth />                  // sidenav row
<ThemeToggle variant="flush" />            // no pad, no radius, no fill
```

## Behavior

**Two positions:** clicking cycles **light ↔ dark**. `system` is not one of
them — it is the *absence* of a choice, so a click can never walk into it
(user ruling 2026-07-30). As a labelled third rung it made the control claim
a mode called "System" when what had actually happened was the user unsetting
their preference, and it left the button unable to say what the next click
would do, because from `system` the result depends on the OS.

The label and the roll slot follow the **resolved** theme rather than the
stored choice, so when the page is unset the button describes what you are
actually looking at. **Alt- or shift-click resets** — it clears the stamp and
the saved key and hands the page back to `prefers-color-scheme` (the same
thing `useTheme().clear()` does). The user law is unchanged: explicit choice
> system > light.

**One glyph, ever** — both positions in the roll strip are the
`mode-toggle-01` split circle, told apart by the label/tooltip. The strip
rolls like a coin (rotation accumulates −180° per slot on the travel clock).
Theme state lives in `useTheme` — this component is only the glyph UI on top
of it.

## Variants

Variants are **container geometry only** (approved spec, 2026-07-30) —
everything else is a prop:

| Variant | Prop | Values | Description |
|---|---|---|---|
| **`button`** — padded rung + corner radius (the button container) | `fill` | **`none` (default)** · `subtle` | the one bg element — `none` = the invisible container (nav rows, sidebars) · `subtle` = the grey filled rung. **The default flipped at 0.10.0**: a bare `<ThemeToggle />` used to render the filled rung, which is why sidebars got a button nobody asked for |
| | `iconRight` | `false` · `true` | glyph right of the text (left default) |
| | `label` | `true` · `false` | text on/off — off pins the square box per rung (28/32/36; icon-only is a geometry condition, not a variant) |
| | `fullWidth` | `false` · `true` | stretches to a sidenav row |
| | `size` | `sm` · `md` · `lg` | moves pad + text + glyph together |
| **`flush`** — no pad, no radius, no fill, ever | `iconRight` / `label` / `fullWidth` / `size` | same | same list minus `fill`; no square pinning — there is no box; `size` scales text + glyph only |

| Size | Container pad | Text class | Glyph +text | Glyph solo (square) |
|---|---|---|---|---|
| sm | 4 · 12 | `kol-mono-12` | 14 | 16 (28box) |
| md | 6 · 16 | `kol-mono-14` | 16 | 20 (32box) |
| lg | 8 · 20 | `kol-mono-16` | 18 | 24 (36box) |

Deprecated aliases render their 0.6.x chrome verbatim: `icon` →
`button + fill none + label off` · `hop` → `button + fullWidth` ·
`hop-bare` → `flush + fullWidth`.
