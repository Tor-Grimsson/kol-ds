<SectionNewsletter headline="Subscribe to the newsletter" body="Get updates on new typefaces." placeholder="Your mail address" submitLabel="Subscribe" onSubmit={subscribe} />

## Behavior

[SectionText](/components/section-text) (label · headline · body, centred) with the email form in its children slot — an email `Input` and a submit `Button`, then an inline success / error status line. The section sits on the family's height ladder (`height`, default `60`, content vertically centred), inside the shared container cap, and takes `theme` like the other sections. The component owns only the form state: `onSubmit(email)` resolving is success (the field clears), rejecting is error; an empty submit errors without calling the handler; the Button disables while pending. `NewsletterBand` is the deprecated alias — `title` → `headline`, `description` → `body`.
