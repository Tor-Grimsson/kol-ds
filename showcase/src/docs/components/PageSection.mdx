## Usage

```jsx
import { PageSection } from '@kolkrabbi/kol-framework'

<PageSection label="01 — Colour" title="Surfaces" body="…">…</PageSection>
```

## Behavior

The framework's page-band section: optional header (label · title · body in
the prose head voice, capped 720px — 960px when `fullbleed`), then children.
`divider` draws the section rule above; `fullbleed` swaps onto the
`kol-page--fullbleed` frame. Retired from the showcase's own doc pages
(2026-07-02 content contract) — its home is consumer sites' marketing/portal
pages.
