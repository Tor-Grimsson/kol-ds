## Usage

```jsx
import { SectionSplit } from '@kolkrabbi/kol-component'

<SectionSplit label="THE FLEET" headline={<>Built to hold <em>course</em></>} body="…" actions={<Button>Explore</Button>} media={<img … />} align="left" />
```

## Behavior

A [SectionText](/components/section-text) column beside the media frame; two columns at/above 901px, one stacked column below. **`align`** is the one prop: `right` (media on the right, default), `left` (media first), `center` (one column, text centred, media below). `meta` and `actions` are mutually exclusive by intent. `caption` gates a gradient veil + mono caption over the media. `FeatureSplit` is this component under its old name and prop names (`kicker` → `label`, `title` → `headline`, `titleSize` → `headlineSize`, `ctas` → `actions`, `mediaAspect` → `ratio`, `flip` → `align="left"`) — a deprecated alias.
