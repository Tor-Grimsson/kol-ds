## Usage

```jsx
import { SettingsPanel, SettingsRow, SettingsSwitch, SettingsChoice, SettingsChipRow, SettingsFooter, Section } from '@kolkrabbi/kol-component'

<SettingsPanel open variant="drawer" title="Display settings" subtitle="website" intro="…" onClose={close} footer={<SettingsFooter customised onReset={reset} />}>
  <Section label="Structure" divided>
    <SettingsRow label="Flat" hint="Ignore folders"><SettingsSwitch label="Flat" on={flat} onChange={setFlat} /></SettingsRow>
  </Section>
</SettingsPanel>
```

## Behavior

One anatomy — header · intro · sections · footer — in two presentations: `drawer` rides [ShellDrawer](/components/shell-drawer) (right-anchored; scrim, Escape, focus trap, scroll lock, focus return, the × control), `overlay` rides FullscreenOverlay (centred; Escape, backdrop dismiss, focus trap). Sections are the DS `Section` with `divided`. The parts: `SettingsRow` (label + hint left, control right — a grid, so a long hint wraps in its own column), `SettingsSwitch` (ToggleSwitch sm; `disabled` + `disabledHint`), `SettingsChoice` (SegmentedToggle sm; options are values or `{ value, label }`), `SettingsChipRow` (toggle chips with counts: `options` as `[{ value, label, count }]`, `selected`, `onToggle`), `SettingsFooter` (`customised` word + `onReset` ghost button). Casing is authored at the call site.
