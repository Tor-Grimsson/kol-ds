## Usage

```jsx
import { SortControls } from '@kolkrabbi/kol-component'

<SortControls options={[{ value: 'name', label: 'Name' }, { value: 'date', label: 'Date' }]} sortBy={sortBy} sortDir={sortDir} onSort={handleSort} />
```

## Behavior

A `flex items-center gap-4` row of [SortHeader](/components/sort-header)s. Click an inactive field → it becomes the sort, ascending; click the active field → the direction flips. `onSort(field)` fires once per click, so the consumer writes one state: `sortBy === field ? flip sortDir : { sortBy: field, sortDir: 'asc' }`. Rides `ContentFilters`' `belowActions` in kol-r2b2's file listing.
