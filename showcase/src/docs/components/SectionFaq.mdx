## Usage

```jsx
import { SectionFaq } from '@kolkrabbi/kol-component'

<SectionFaq label="FAQ" headline="Questions, answered" items={[{ q, a }]} singleOpen defaultOpen={0} />
```

## Behavior

The one new surface in the section family — the behaviour already shipped in [Accordion](/components/accordion); this is the section around it: a [SectionText](/components/section-text) header over `{ q, a }` panels. `singleOpen` closes the others when one opens.
