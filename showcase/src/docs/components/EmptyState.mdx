## Usage

```jsx
<EmptyState eyebrow="Phase 2" title="Layer inspector" body="Select a layer to edit its properties." />
```

## When to use

The stacked "nothing here yet / nothing selected" text block for inspectors,
empty rails and unshipped panels — eyebrow · title · optional body · optional
footer above a top hairline. **All lines render as authored** — the source's
auto-uppercase eyebrow was dropped per the KOL no-auto-casing rule.
