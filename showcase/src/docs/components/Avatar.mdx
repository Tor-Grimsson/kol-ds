## Usage

```jsx
import { Avatar } from '@kolkrabbi/kol-component'

<Avatar initial="TG" size="md" />
```

## Behavior

An initials circle, not an image: renders `initial` centered on a
surface-secondary fill in the narrow face. Four sizes (sm 32 → xl 96) with a
matched helper type class per rung. Shared primitive — kol-content's author
rows compose it.
