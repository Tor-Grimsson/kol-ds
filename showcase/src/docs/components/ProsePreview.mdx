```jsx
<ProsePreview h1='Page title' paragraph='…' code='const x = 1' pullout='…' />
```

## When to use

A full rich-text specimen: one `.kol-prose` block exercising every long-form
element — the H1–H4 ladder, section lede, body paragraph, blockquote,
indented passage, code block, pullout and both list kinds — so the prose
stylesheet can be reviewed end-to-end in one view. Fixed structure; only the
text slots vary. **All styling comes from the prose stylesheet** — none lives
here. The "long-form" member of the type-specimen kit.
