## When to use

The chip family splits three ways (chip law, 2026-07-30): **Pill** is the
static label, **Tag** is the interactive/filterable chip, **Badge** — this one
— is **system status or a count**. If the chip states a fact the system
produced (new, error, 3 unread), it's a Badge; if a human authored it as a
label, it isn't.
