## Usage

```jsx
import { SizeOrDownload } from '@kolkrabbi/kol-component'

<SizeOrDownload href={downloadUrl}>2.4 MB</SizeOrDownload>
```

## Behavior

A link that reads as the file size at rest and, on hover, swaps to the download glyph sliding out from behind the word plus the label — 500ms on the house curve, the glyph delayed 200ms on entry only. Clicking confirms as "Downloaded" for 2s (the confirm is local, not ActionButton's); with `href` the browser downloads, without one the click is the confirm alone. One type class throughout (`kol-mono-12`), ink on the opacity scale. Promoted verbatim from the content-card comparison set (ContentFiltersCollection, 2026-08-27).
