## Usage

```jsx
import { InspectorSection } from '@kolkrabbi/kol-component'

<InspectorSection label="Aspect" divided>…</InspectorSection>
```

## Behavior

A small-caps label above a vertical content stack. `divided` adds the between-siblings hairline — set it on every section in a stack. Renamed from `Section` 2026-08-26 (the website-section family owns the `Section*` prefix); `Section` stays exported as a deprecated alias.
