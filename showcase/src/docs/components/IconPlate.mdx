## Usage

```jsx
import { IconPlate } from '@kolkrabbi/kol-component'

<IconPlate size={48} ground="light" guide><Icon name="chevron-down" size={48} /></IconPlate>
```

## Behavior

The ground, the keyline guide and the glyph share one square: a 20 plate is 20px, and the guide is the
glyph's own 24-unit grid. The ground is a specimen ground — light or dark paper the app theme never
touches. The plate draws no glyph; pass one sized to the plate. `size="fill"` takes the parent's width and
stays square. `KeylineGuide` is the guide on its own, for a positioned parent.
