## Usage

```jsx
import { ContentCard } from '@kolkrabbi/kol-component'

<ContentCard variant="catalog" title="Empty 7U" detail="7U — power, perf, patch" expanded={open} expandedContent={<>…<Button>Use preset</Button></>} onClick={toggle} />
```

## Behavior

Six variants over one anatomy — `default · catalog · print · article · work · typeface` — differing in text composition, media ratio and the ruled box (see the [content card system](/docs/content-card-system)). Text slots (`title · body · kicker · detail · date · size · meta · tags`) render through [ContentText](/components/content-text); every type class is a seam (`titleClass` and friends). **`expanded`** (catalog · print): the card grows to a 2×2 grid cell and flips to a row — media right at 50%, `expandedContent` left on `pad-card-lg` — the GridCard behaviour. A card with `href` is an `<a>`; with `onClick` an operable `<article>`.
