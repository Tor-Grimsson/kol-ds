## Usage

```jsx
import { SectionText } from '@kolkrabbi/kol-component'

<SectionText label="THE STUDIO" headline="One text block, every section" body="…" actions={<Button>Read more</Button>} />
```

## Behavior

Every slot is opt-in — pass only what the section needs and nothing else renders. Headlines balance (`text-wrap: balance`, theme ≥0.69.0) — no orphaned last word. Type is picked by **role** (`headlineSize`), never a threaded class. The **label is uppercase by role** (`.kol-section-text-eyebrow`); headline, body and actions render as authored. Every default class is a seam: `labelClass` / `bodyClass` / `actionsClass` replace the string whole, which is how the hero's eyebrow and the CTA's rows wear their own voices on the same anatomy. `children` render between body and actions (the split's stats strip). Sibling of [ContentText](/components/content-text) — that one is ruled to the card type ramp and has no actions slot.
