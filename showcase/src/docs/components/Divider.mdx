## Usage

```jsx
import { Divider } from '@kolkrabbi/kol-component'

<Divider />
```

## Behavior

Defaults to `bg-fg-08` — the 8% ink line that holds in both themes. `opacity`
takes any stop on the fg ladder (01–96). The `vertical` variant wraps itself
in a div so it behaves in flex rows without the caller managing stretch.
