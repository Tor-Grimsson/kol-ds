## Usage

```jsx
import { Section } from '@kolkrabbi/kol-component'

<Section label="Aspect">…</Section>
```

## When to use

The labeled control group for inspector/editor panels — a small-caps label
above a vertical content stack: `<Section label="Aspect">…</Section>`. For a
label wired to a single control, use
[LabeledControl](/components/labeled-control) instead.
