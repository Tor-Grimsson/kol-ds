## Usage

```jsx
import { SpecimenSample } from '@kolkrabbi/kol-styleguide'

<SpecimenSample label="Sans, 700, 48/52" weight={700} size={48} lineHeight={52}>Hamburgefonstiv</SpecimenSample>
<SpecimenSample horizontal label="Bold" weight={700} size={28}>ABCDEFGHIJKLMNOPQRSTUVWXYZ</SpecimenSample>
```

## Behavior

The library master `SpecimenSample` (Styleguide page; it was kol-foundry's `TypeSample`, now an alias on the retirement ledger). The atomic unit of the Specimen kit: an optional mono caption over one
paragraph whose typography is driven entirely by props via inline style —
**arbitrary px values are the point**, so props map to inline style rather
than fixed kol- size stops. Stack several to show a scale, a weight range or
a family; adjacent samples get a hairline separator automatically. Label and
children render verbatim as authored. `horizontal` puts the caption beside the sample, left, in the sample's own type (the font sheet's weight rows), with no hairline. Stack them in a `SpecimenSampleGroup`.
