## Behavior

The app-site navigation rail, replicated from the elder reference
(kol-website apps/brand, 2026-08-09 user mandate). **Two levels only**: a
category is a disclosure button — icon, label, trailing caret — whose pages
list opens in place; a category with `to` and no `pages` (Home) renders as a
plain link row. Disclosure is independent per category and loads closed.
The active category is derived from the route — no resolver prop.

**One control: the pill-marked grab edge** (2026-08-09 build order — the
chip Button is gone in both states). Click toggles expand↔collapse (a 3px
slop keeps toggle presses from jitter-resizing); drag resizes, snap-collapses
under the threshold, and snap-to-defaults on release near the stylesheet
width; keyboard on the focused separator: arrows resize, Home resets,
Enter/Space toggle. Everything drives `:root[data-sidenav="collapsed"]` and
the `kol-sidenav` storage schema.
Collapsed rows carry a DS [Tooltip](/components/popover-panel); the footer
wordmark swaps for its initial; the built-in
[ThemeToggle](/components/theme-toggle) falls back to its icon variant.
Distinct from the workshop's ShellSidebar (grouped doc trees).
