## Usage

```jsx
import { SortHeader } from '@kolkrabbi/kol-component'

<SortHeader label="Date" active dir="desc" onClick={flip} />
```

## Behavior

The strip chrome: `kol-helper-12`, uppercase label, 1px tracking, `select-none`; active `text-oq-96`, rest `text-oq-48 hover:text-oq-64`. The arrow renders only on the active field — arrow-down is ascending (A→Z, oldest→newest), arrow-up descending. Promoted from kol-r2b2's FileList (ContentFiltersCollection, 2026-08-27). [SortControls](/components/sort-controls) is the group.
