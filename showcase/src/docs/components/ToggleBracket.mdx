## Usage

```jsx
import { ToggleBracket } from '@kolkrabbi/kol-component'

<ToggleBracket label="Snap" value={on} onToggle={setOn} />
```

## Variants

Text-pair toggle showing `Label [STATE]`. `default` is the filled shell
(bg-surface-secondary) that flips to accent-yellow with navy ink when ON;
`plain` is bare text rows with no chrome — for inline contexts like sidenav
child rows and dense panels.
