## Usage

```jsx
import { BrandHero } from '@kolkrabbi/kol-framework'

<BrandHero label="Kolkrabbi" title="Brand portal" lede="…" />
```

## Behavior

The top-of-page hero in the prose head voice: optional `kol-prose-label`
eyebrow, then `mark` (a logo/graphic node) beside the `kol-prose-display`
title and an optional lede capped at 60ch. For sub-pages with a back link use
[SubPageHero](/components/sub-page-hero).
