## Usage

```jsx
import { SectionLabel } from '@kolkrabbi/kol-component'

<SectionLabel text="Featured work" />
```

## Behavior

Icon + text section label in three sizes — sm 16 / md 20 / lg 32, each
pairing the icon size with the matching helper/heading class. Migrated off
the deleted legacy `kol-label-*` family (2026-07-15); **no text-transform** —
labels render as authored.
