```jsx
<MenuDropdownItem onClick={fn}>Save</MenuDropdownItem>
```

## Behavior

The row atom of the [MenuItem](/components/menu-item) family — one action per
row inside the popover panel. The same rows also serve
[ShapeDropdown](/components/shape-dropdown)'s variant menu.
