## Usage

```jsx
import { SectionCards } from '@kolkrabbi/kol-component'

<SectionCards headline="What we make" body="…" features={[{ title, icon, visual, description, href }]} actions={<Button>Explore</Button>} />
```

## Behavior

A [SectionText](/components/section-text) header over a responsive row of [CardFeatureItem](/components/card-feature-item) cards, capped by an optional centred action row. Every block is presence-gated. Card links are plain anchors; pass `onNavigate` to intercept same-tab navigations. `FeaturesCardSection` is the deprecated alias (`headerLabel` → `headline`, `headerDescription` → `body`, `ctas` → `actions`).
