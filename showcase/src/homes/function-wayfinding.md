# Wayfinding

How a user **moves through or re-slices a site** — filtering, search, site chrome: ContentFilters, DropdownTagFilter, ShellSearchOverlay, ShellDrawer, DocsToc.

Function is the second way to order Components: what a component is **for**, where the atomic ladder orders by what it **is**. The set is closed — a new component slots into one of these ten.
