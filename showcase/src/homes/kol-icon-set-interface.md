# Interface

**Interface** (`kol-icon-set-interface`, called V1 until 2026-09-30) is the app chrome: navigation, files, layout, playback, typography — and the editor's own tool icons, which joined it in the 2026-09-27 one-icon-system pass (the **tools**, **editing** and **shape** groups). Single stroke cut, `currentColor`, one name per glyph — `<Icon name="…" />` from `@kolkrabbi/kol-icons`.

**Groups:** direction (32), actions (50), navigation (17), status (34), layout (66), files (48), charts (46), flow (32), design (138), shapes (48), typography (28), media (36), devices (38), code (11), people (67), commerce (39), places (37), planning (47). The groups are the categories (kol-icons 0.58.0); the batch joined in 0.59.0.
