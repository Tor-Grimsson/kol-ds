# Components

Every component the KOL packages ship, on one ladder. A component is placed by **what it is** — its anatomy and role — never by which package ships it or what it imports.

| Chapter | Is |
|---|---|
| Atoms | one interface element that paints and stands alone — a button, a knob, a swatch |
| Molecules | a small assembly of nameable parts working as one — label + control, a card, a row |
| Organisms | a self-contained region — a bar, a table, a gallery, an editor |
| Utilities | purpose without a face — a wrapper, a mechanism other components wear, a guard |

**Order by** changes the view, not the placement: *Atomic* (the ladder), *Function* (what it does for a user — input, display, overlay…) or *Package* (who ships it). A package's components also have their own page under Packages.

The law behind the ladder is the component taxonomy in the documentation.
