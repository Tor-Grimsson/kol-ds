# Blocks

A block is a **composition of shells and tools** — a sidenav, a header, a footer, a hero, a panel, a toolbar — built from the published components, and shown at every width so you can see **how it breakpoints**.

A block is copied whole into a page. It is not a package's family (that is a set) and not a single component: it is the arrangement.

Blocks are grouped by what part of a page they are. Each block page carries its source, the components it composes, and a resizable preview.
