# Group by

Components are ordered one of two ways. The choice changes the chapters in the left rail and the sections on the Components page; it never moves a component.

- **Atomic** (default) — by what a component **is**: Atoms, Molecules, Organisms, and Utilities for the ones with no face. Each tier has its own page.
- **Function** — by what a component is **for**: Action, Input, Display, Feedback, Navigation, Wayfinding, Overlay, Media, Structure, Utility. Each function has its own page.

**Package is not a grouping — it is a filter.** Filtering by package keeps you in Components and shows the components that package ships; a package's sets live under Sets.
