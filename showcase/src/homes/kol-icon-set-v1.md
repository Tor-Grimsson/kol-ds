**V1** (`kol-icon-set-v1`) is the app chrome: navigation, files, layout, playback, typography — and the editor's own tool icons, which joined it in the 2026-09-27 one-icon-system pass (the **tools**, **editing** and **shape** groups). Single stroke cut, `currentColor`, one name per glyph — `<Icon name="…" />` from `@kolkrabbi/kol-icons`.
