# Styles

The reference lookup. Every page here reads its values **straight off the installed packages** — nothing is typed twice, so what you see is what a consumer gets.

| Chapter | Holds |
|---|---|
| Foundations | tokens, color, typography, tones — each page names the CSS it reads |
| Icons | the two shipped icon sets: **V1**, the app chrome (the editor's tool icons live in its tools · editing · shape groups), and **Signal**, the instrument and control vocabulary |
| Guides | the standards written as live pages: shell and layout, menus, loaders, type roles |

The rules these values obey are written in Docs › Documentation › Foundations.
