# Organisms

An organism is a **self-contained region** of an interface — a full bar, a table, a gallery, a band, an overlay surface, a manager, an editor. It composes molecules and atoms into something a page is built from.

The line against a molecule is scale and independence: a molecule is a unit you place inside a region; an organism *is* the region. A page shell, a settings scaffold, a chess board with its sidebar, a media library — organisms.
