# Apps

The tools built on the design system, each running on fake data. A tool's features ship in the packages; the app is where they are judged, at every width, before a consumer adopts them.

An app is built in layers — an engine underneath, a shell around the work, a hub of standard pages, the tool itself — and each layer has its own reference app. The diagram below is how they nest; each layer's page lists its apps.
