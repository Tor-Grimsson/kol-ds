# Docs

The `docs/` folder of this repo, rendered live. Every page is a markdown file with frontmatter, read by kol-workshop's markdown engine — the same files open in Obsidian.

| Category | Holds |
|---|---|
| Documentation | the design system: foundations, icons, components, compositions, brand, breakpoints — **the law** |
| Operations | the machinery around it: releases, the showcase, the content pipeline, the apps tier, the phase log |

A chapter's header opens its own index page. Frontmatter (type, status, tags, dates) sits at the top of every page; `F` hides or shows it.
