# Signal

**Signal** (`kol-icon-set-signal`) is the instrument vocabulary — the icons of the rack, the generators and the effects: waves, cables, filters, logic, sequencing, dither. The control icons live here, not in Interface. Same rules: single stroke cut, `currentColor`, `<Icon name="…" />`.

**Groups:** ascii (10) · cable (5) · cap (3) · color (4) · curve (2) · dither (12) · filter (4) · generator (4) · gradient (3) · line (5) · logic (6) · pattern (1) · radial (7) · ramp (3) · sequence (4) · shape (7) · shaper (8) · transport (8) · wave (5)
