# Cards

Website cards: the **sections a marketing site is built from**, each shown live and at every width — heroes, text and image splits, calls to action, signup, feature cards, FAQ and content cards. Every card carries its source to copy.

| Chapter | Holds |
|---|---|
| Heroes | full-bleed media, split, text-only, carousel, foot-pinned |
| Text & image | text left image right, image left, centred column, image above, full-bleed |
| Calls to action | editorial, centred, connect |
| Signup | newsletter |
| Features | image cards, FAQ |
| Content cards | bento tiles, the article card and its variants |

A card is neither a block (a composition of shells and tools) nor a set (a package's family): it is one section of a page, made from the `Section*` components and the content cards.
